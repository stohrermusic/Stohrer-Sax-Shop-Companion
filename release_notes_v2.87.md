# v2.87

- Scrap Mode: the progress window now shows the pads on the current scrap separately from Done and Remaining.
- Frame & Cut: the "Is the lid closed?" prompt now has Yes / No buttons.
- Pad Maker: the "mid" size-label position (was "ctr") now sits exactly halfway between the center hole, or the center if there is no hole, and the edge.
- A ready-made Sizing Rules preset with Matt's own label fonts and positions, "Matt mode", is in the `presets` folder on GitHub; import it from Options > Sizing Rules if you want to use it.
- Darted leather: the "out" label position is now measured from the dart valley instead of the outer edge, so one value keeps the label just inside the valley at every size.
- Bug fixes.
